# Погодный бот ВКонтакте

Чат-бот для сообщества ВКонтакте, который показывает текущую погоду и прогноз на 3 дня по любому городу мира.

## Логика работы

Основной сценарий диалога:

```
/start
  │
  ├─► Приветствие + главное меню (reply-кнопки)
  │
  ├─► [Погода]
  │     │
  │     ├─► Показать inline-кнопки быстрых городов
  │     │   + запросить ввод города текстом
  │     │
  │     ├─► Пользователь ввёл город → валидация
  │     │     ├─ валидно   → Nominatim → Open-Meteo
  │     │     │            → сохранение в БД → вывод прогноза
  │     │     └─ невалидно → подсказка + повторный запрос
  │     │
  │     └─► Пользователь нажал inline-кнопку города
  │           → тот же путь, что и при вводе текстом
  │
  ├─► [Мой город]  → показать сохранённый город
  ├─► [История]    → последние 5 запросов из БД
  └─► [Помощь]     → справка

Любой другой ввод → возврат в главное меню с подсказкой.
```

Диаграмма состояний (FSM):

```
MENU ──► [Погода] ──► WAITING_CITY ──► MENU
         ▲                              │
         └── [Меню / Назад] ◄───────────┘
```

## Инструкция по запуску

### Требования

- Python 3.11+
- Сообщество ВКонтакте с включёнными сообщениями
- Токен доступа с правами «Сообщения сообщества» и «Управление сообществом»

### Быстрый старт

1. Клонируйте репозиторий:

   ```bash
   git clone <URL>
   cd <project>
   ```

2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   ```

3. Скопируйте шаблон настроек и заполните токен:

   ```bash
   cp .env.example .env
   ```

   Откройте `.env` и укажите `VK_TOKEN`.

4. Проверьте готовность проекта:

   ```bash
   python smoke_test.py
   ```

5. Запустите бота:

   ```bash
   python -m app.main
   ```

6. Напишите сообществу `/start` в личные сообщения.

### Как получить VK_TOKEN

1. Управление сообществом → «Работа с API».
2. Создайте ключ с правами «Сообщения сообщества» и «Управление сообществом».
3. В разделе «Long Poll API» включите Long Poll версии 5.199 или новее
   и тип события «Входящие сообщения».

## Эндпоинты и интеграции

Бот использует **Long Poll API ВКонтакте**, входящие вебхуки не требуются.

Внешние HTTP-сервисы:

| Сервис                        | Назначение                              | Метод              |
| ----------------------------- | --------------------------------------- | ------------------ |
| `nominatim.openstreetmap.org` | Геокодинг: название города → координаты | GET `/search`      |
| `api.open-meteo.com`          | Прогноз погоды по координатам           | GET `/v1/forecast` |

## Лимиты внешних API

Оба сервиса бесплатны для некоммерческого использования без ключа.

| Сервис          | Ограничение                                                        |
| --------------- | ------------------------------------------------------------------ |
| Nominatim (OSM) | Не более 1 запроса в секунду с одного IP. Обязателен `User-Agent`. |
| Open-Meteo      | 10 000 запросов в сутки, 5 000 в час, 600 в минуту.                |

Ограничения учтены в коде: таймаут 15 секунд, до 2 повторных попыток
при сетевых ошибках с экспоненциальной задержкой.

## Архитектура

```
app/
├── bot/              слой адаптеров VK (handlers, keyboards, states, deps)
├── db/               ORM-модели, репозиторий, асинхронная сессия
├── domain/           бизнес-логика сценария и пользовательские тексты
├── services/         интеграции с внешними API и валидаторы
├── config.py         загрузка настроек из .env
└── main.py           точка входа, запуск Long Poll
```

Разделение слоёв:

- `bot/` — только обработка событий VK и формирование ответов;
- `domain/` — сценарий (FSM + бизнес-правила), независим от VK;
- `services/` — внешние зависимости с изоляцией сетевых ошибок;
- `db/` — персистентное состояние, изолировано за репозиторием.

Технологии:

- **vkbottle 4.x** — асинхронный фреймворк для VK API
- **SQLAlchemy 2.0** — ORM с async-драйвером `aiosqlite`
- **aiohttp** — асинхронные HTTP-запросы
- **python-dotenv** — загрузка настроек

## Docker

Сборка и запуск:

```bash
docker compose up --build
```

Файл `.env` должен быть подготовлен заранее.
Данные SQLite сохраняются в каталог `data/` на хосте через volume.
